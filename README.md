# HRBP-конструктор

Одностраничный адаптивный сайт — интерактивный гид по типовым HR-ситуациям: как думает бизнес-партнёр по персоналу.

**Демо-кейсы на обезличенных данных. Названия компаний и сотрудников изменены.**

## Что внутри

5 разборов типовых ситуаций, каждый по единой методологии:

- ⚡ Конфликт в команде
- 📉 Сотрудник не справляется
- 🔄 Оргизменения и тревожность
- 🚪 Сложное увольнение
- 🔥 Выгорание ключевого сотрудника

Каждый кейс раскрывается в блоках: «Ситуация» → «Что видит HRBP» → «Какие вопросы задаёт» → «План действий» → «Когда подключать других» → «Принцип».

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | стили (корпоративный стиль, синие и серые тона) |
| `app.js` | логика: загрузка кейсов и навигация |
| `cases.json` | **все тексты кейсов** — редактируется без кода |

## Как редактировать кейсы

Все тексты лежат в `cases.json`. У каждого кейса:

- `id` — идентификатор (используется в ссылке, например `#burnout`);
- `title`, `short` — заголовок и краткое описание для плитки;
- `icon` — эмодзи для плитки и шапки кейса;
- `color` — HEX-код акцентного цвета кейса;
- `situation`, `sees`, `questions`, `steps`, `escalation`, `principle` — тексты блоков.

После правок достаточно обновить страницу — код менять не нужно.

## Как запустить

Файлы статические, но `cases.json` загружается через `fetch`, поэтому нужен любой локальный сервер, например:

```bash
cd hrbp-constructor
python -m http.server 8000
```

и открыть http://localhost:8000

Либо просто открыть папку в VS Code через расширение Live Server.
